Privacy Policy

Last updated: March 9, 2026

Fill It Pro ("the Extension") is a Chrome browser extension that helps users extract data from PDF documents and auto-fill web forms. This policy explains what data the Extension accesses, how it is used, and how it is protected.

Data We Process

When you use Fill It Pro, the following data is processed:

  • PDF documents you upload — The content of PDFs you select or drag into the Extension is read locally in your browser and sent to the Anthropic API for data extraction.
  • Your API key — Your Anthropic API key is stored locally in your browser using Chrome's built-in sync storage (chrome.storage.sync). It is only used to authenticate requests to the Anthropic API.

How Your Data Is Used

PDF content is sent to Anthropic's Claude API solely to extract structured data (names, addresses, vehicle information, etc.) for the purpose of filling web forms. The Extension does not use your data for any other purpose.

Third-Party Services

The Extension sends PDF data to Anthropic's Claude API for processing. Anthropic's use of data sent through their API is governed by their own privacy policy and API terms of service. Per Anthropic's API terms, data sent through the API is not used to train their models.

Data Storage

  • Your API key is stored locally in your browser via chrome.storage.sync.
  • PDF content and extracted data are held in memory only during processing and are not persisted to disk or any external server controlled by us.
  • The Extension does not maintain any external database or server.

Data We Do NOT Collect

  • We do not collect analytics or usage data.
  • We do not track your browsing history.
  • We do not store your PDF documents or extracted form data.
  • We do not sell or share any data with third parties beyond the Anthropic API call described above.

Permissions

The Extension requests the following Chrome permissions:

  • activeTab — To access the current page's form fields for auto-filling.
  • storage — To store your API key locally.
  • scripting — To inject the form-filling script into the active tab.

Your Control

You are in full control of your data. You can remove your API key at any time from the Extension's options page, and uninstalling the Extension will remove all locally stored data. No data remains on any server we operate because we do not operate any servers.

Changes to This Policy

If this policy is updated, the changes will be posted on this page with a revised date. Continued use of the Extension after changes constitutes acceptance of the updated policy.

Contact

If you have questions about this privacy policy, you can reach us by opening an issue on our GitHub repository.
